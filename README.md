# STUDENT RECORD MANAGEMENT SYSTEM

A student record database for managing a list of sudent details.

To compile
```
make
```

To run executable
```
./student
```

## Functionality summary
```
Option and Required Functionality
a/A: Add a new dynamically allocated student record.
d/D: Delete by roll number or name.
s/S: Display the complete list in tabular form.
m/M: Modify a record by roll number, name or percentage.
v/V: Save records to student.dat.
e/E: Save & exit or exit without saving.
t/T: Sort by name or percentage.
l/L: Delete all nodes and free memory.
r/R: Reverse the singly linked list.
```
